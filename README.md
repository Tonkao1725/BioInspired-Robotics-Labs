### ขอบเขตหลักฐานและข้อควรทราบสำหรับการตรวจ

- เวลาในตารางมาจาก **Author/Committer timestamps ใน Git metadata** ซึ่งสามารถเปิดตรวจสอบรายละเอียด Commit และไฟล์ที่เปลี่ยนได้จากลิงก์
- วันที่ใน Commit **ไม่ใช่หลักฐานยืนยันวันและเวลาที่ Push ขึ้น GitHub** และไม่ใช่หลักฐานยืนยันว่าอาจารย์ได้รับงานภายในกำหนดส่งแต่ละ Week
- การบันทึก Commit ไม่ได้หมายถึงการรับรองว่าเนื้อหาทดลองถูกต้อง หรือเป็นการยืนยันคะแนน
- ไม่ได้แก้ย้อนหลังหรือสร้าง Commit เก่าขึ้นใหม่เพื่อเปลี่ยนวันที่ในตารางนี้
- กรุณาเก็บ Repository นี้ไว้เป็นหลักฐานประวัติ ไม่ลบหรือเขียนประวัติ Git เดิมใหม่ และนำลิงก์มาประกอบกับ Fork ของผู้สอนเมื่อจัดการโอนงานเสร็จ
- การยอมรับหลักฐานสำหรับการส่งงานย้อนหลังเป็นการตัดสินใจของผู้สอน
